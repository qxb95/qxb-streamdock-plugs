# 🎵 StreamDock 音乐控制插件

> 让你的 StreamDock 成为音乐控制中心 —— 无需任何配置，即插即用，自动识别当前播放的音乐，一键控制播放/暂停。

---

## 产品简介

**音乐控制插件**是为 StreamDock 设备量身打造的一款实用工具，它能让你的 StreamDock 按键实时显示当前播放的歌曲名称，并根据播放状态自动滚动或静止，同时支持一键控制音乐的播放与暂停。

无论你在使用 QQ 音乐、网易云音乐、Spotify，还是浏览器中的网页音乐，插件都能自动识别，无需任何手动设置，真正实现“打开即用”。

---

## ✨ 核心功能

- **🎵 实时歌曲显示**：自动获取当前正在播放的歌曲名称和歌手，清晰显示在 StreamDock 按键上。
- **🌀 智能滚动效果**：播放时歌曲名称自动循环滚动，暂停或停止时立即静止，状态一目了然。
- **⏯️ 一键播放/暂停**：按下 StreamDock 按键即可切换音乐播放状态，无需切换到音乐应用，操作更高效。
- **🖼️ 自定义背景图片**：支持设置个性化按键背景（将 `icon.png` 放入插件目录即可），打造专属视觉风格。
- **📱 自动识别新应用**：即使音乐软件在插件之后打开，也能立刻获取歌曲信息，实时同步。
- **🌐 全平台兼容**：兼容主流音乐软件及浏览器网页播放，不受应用限制。

## 🔧 安装与使用

1. **下载插件**：获取 `MusicPlugin` 插件文件夹。
2. **安装到 StreamDock**：将文件夹复制到 StreamDock 的插件目录（通常位于 `%AppData%\HotSpot\StreamDock\plugins\`）。
3. **重启 StreamDock**：插件将自动加载。
4. **添加动作**：在 StreamDock 软件中，将“音乐控制”动作拖拽到任意按键即可使用。

> 💡 **提示**：如果你希望更换按键背景，只需在插件文件夹中放置一张 `icon.png` 图片（推荐尺寸 100×100 像素），插件会自动应用。

## ❓ 常见问题

**Q：为什么我的歌曲名称不显示？**  
A：请确保有音乐应用正在播放，并且系统媒体控制功能正常（可尝试按键盘上的多媒体键测试）。插件会在音乐播放后自动识别。

**Q：按键按了没反应？**  
A：插件使用模拟多媒体键方式控制，与键盘上的播放/暂停键效果一致。如果键盘多媒体键可用，则插件一定有效；否则请检查系统多媒体键设置。

**Q：滚动状态与音乐不同步？**  
A：插件通过检测系统音频输出来判断播放状态，非常准确。如果发现不同步，请检查音乐应用的音频输出是否正常。

**Q：支持哪些音乐应用？**  
A：支持所有向 Windows 系统报告媒体信息的应用，包括但不限于 QQ 音乐、网易云音乐、Spotify、酷狗音乐、浏览器（如 Chrome、Edge 中的网页音乐）等。
